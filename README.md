# ⚡ VLSI Learning

A repository documenting my journey in **VLSI design**, from digital logic fundamentals and Verilog HDL to RTL design, simulation, and FPGA development.

---

## 🎯 About This Repository

This repository serves as a hands-on record of my VLSI learning journey.

It contains:

* 💡 Digital logic designs
* 💻 Verilog HDL implementations
* 🧪 Testbenches and simulations
* 📊 Simulation waveforms
* 🔗 RTL schematics
* ⚙️ Synthesis and implementation experiments
* 🚀 VLSI design projects
* 📝 Learning notes and concepts

The goal is to learn VLSI by **designing, simulating, and analyzing actual hardware designs** rather than only studying the theory.
